ESTOQUE E2X - WINDOWS 10
==========================================

PRIMEIRO USO
1. Copie ou extraia esta pasta no computador que vai servir o sistema.
2. Deixe o SSD externo conectado como unidade E: (opcional, só para backup).
3. Clique duas vezes em INSTALAR_PRIMEIRO_USO.bat.
4. Depois, clique duas vezes em INICIAR_ESTOQUE.bat.
5. No primeiro início, a janela preta mostra os usuários administrativos
   criados automaticamente (usuário e senha temporária). Anote antes de
   fechar a janela - ela não aparece de novo. Cada pessoa troca a própria
   senha no primeiro login. Depois, use a aba "Usuários" (como admin) para
   cadastrar o restante da equipe.

USO DIARIO
- Abra o sistema com INICIAR_ESTOQUE.bat.
- Mantenha a janela preta aberta enquanto outras pessoas estiverem usando.
- Neste computador, o endereço é http://localhost:3000.
- Para descobrir o endereço dos outros computadores, execute DESCOBRIR_IP.bat.
- Cada pessoa faz login com seu próprio usuário e senha.

BACKUP
- Conecte o SSD como E:.
- Feche o sistema para garantir uma cópia consistente.
- Execute FAZER_BACKUP.bat.
- Os backups ficam em E:\Estoque_E2X\Backups.

RESTAURACAO
- Feche o sistema.
- Execute RESTAURAR_ULTIMO_BACKUP.bat.
- Digite SIM quando solicitado.

IMPORTANTE
- O computador principal precisa permanecer ligado para os outros acessarem.
- Todos devem estar na mesma rede local.
- No primeiro uso, a instalação precisa de internet.
- Depois de instalado, o sistema e o banco funcionam 100% localmente, sem
  internet e sem depender de nenhum serviço externo.
- Se o Windows perguntar sobre Firewall, permita o acesso em redes privadas.
